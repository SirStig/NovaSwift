Before you play

What you'll need.

Your EV Nova data

NOVA Swift is an engine, not a copy of the game. You need the data files from your own EV Nova install (the Windows version's files or a Mac Nova Files folder). The setup wizard finds and imports them.

Adding your data

A reasonable machine

macOS 14 or later, iOS and iPadOS 17 or later, tvOS 17 or later, or a 64-bit (x86_64) Linux PC or Steam Deck. The Linux beta is new, so expect rough edges.

Build it yourself

From source.

The Apple app needs a Mac with Xcode. Clone the repository, run the setup script, put your EV Nova data in data/base/, open the project and run any target: macOS, iOS, iPadOS or tvOS.

The Godot frontend and the dedicated server have their own packaging scripts for Linux, Windows and macOS.

RepositoryPACKAGING.md

# clone and fetch dependencies
git clone https://github.com/SirStig/NovaSwift.git
cd NovaSwift && scripts/setup.sh

# put your own EV Nova data in data/base/, then
open app/NovaSwift.xcodeproj
