Joining a server

Linux and Steam Deck: open Multiplayer, find the server in the browser (or Quick Connect with the address), and join. You need the same game version and the same gameplay plug-ins; the game tells you what's missing.

List your server

Run the dedicated server, open Public listing in its admin panel and press the pull-request button: it prepares the servers.json entry for you.

How to get listed

How status works. The list is a file on GitHub, so anyone can read it and nothing here runs a server. Every 15 minutes a GitHub workflow asks each server for its status (the same UDP query the game uses) and the page shows that result. In the game, the browser pings each server live and shows your own latency. Rules labels are set by each server's owner: Safe means PvP losses aren't real, Full stakes means they are.
