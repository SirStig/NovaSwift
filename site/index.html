EV Nova, flying again.

A rebuild of the 2002 space game in Swift. It runs natively on Mac, iPad, iPhone and Apple TV, with Linux and Windows in progress. You need your own copy of the game.

Play the TestFlight beta Source on GitHub
  • macOS · iPadOS · iOS · tvOS
  • Native Swift, not an emulator
  • You bring the game data

Progress

Checked against the original code.

We decompiled the original game and compared every part of it with NovaSwift. Original behaviour is the default; a few optional Enhancements live in Settings.

This shows how much has been compared, not that the game is finished. NovaSwift is in beta and still has bugs. See the details or report something that plays differently.

Get it

Play the beta or build it.

The TestFlight beta covers all four Apple platforms.
To build it yourself you need a Mac with Xcode. Your game data stays on your machine.

Join the beta Adding your data 
# clone and fetch dependencies
git clone https://github.com/SirStig/NovaSwift.git
cd NovaSwift && scripts/setup.sh

# drop your own EV Nova data into data/base/

# then open it in Xcode, pick a target, hit Run
open app/NovaSwift.xcodeproj

You bring the game.

EV Nova's content belongs to ATMOS. This project ships no game data and never will. It reads a copy you own, at runtime, the same way OpenMW and OpenRA work.
