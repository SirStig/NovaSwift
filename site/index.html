EV Nova, rebuilt in Swift.

Reverse-engineered from the 2002 original. Native on Mac, iPad, iPhone and Apple TV. Bring your own copy of EV Nova.

Join the beta Read the source

Every system, checked against the original executable.

The original Windows build (EV Nova CE) was reverse-engineered and studied in a decompiler. Each gameplay system was compared with NovaSwift and rewritten to match it. Original behaviour is the default.

Function-by-function progress · Reverse-engineering notes

Install, reorder and toggle plug-ins.

Browse the community catalog and install in one tap. Installs work offline for anything you already have. Or import your own files, including old Mac .sit and .hqx archives.

  • Enable, disable, reorder and delete
  • Import classic EV Nova pilots
  • Add your own plug-in by pull request

A full plug-in editor, inside the app.

Available on macOS. Edit every resource type, draw the galaxy, and play your plug-in in a live game session before you ship it.

  • Schema-driven inspectorEvery EV Nova resource type, with a hex view for anything the schema doesn't cover.
  • Galaxy mapPlace and drag systems, draw and erase hyperlinks, set government colours and nebulae.
  • Live previewThe effective game data, reloaded in place as each edit lands.
  • Test runA full game session on your plug-in, with a debug panel to spawn fleets, grant outfits, set control bits and start missions.
  • Story graphControl-bit analysis across missions, events and storylines.
  • Linter and exportCatches dangling references and missing sprites. Exports classic resource files or an HD pack.

Fly the same galaxy as your friends.

Co-op over local Wi-Fi or Game Center. The host sets the rules, and there are no servers to run.

  • PvP
  • Real damage
  • Friendly fire
  • Permadeath
  • Player trading

Every campaign, step by step.

The Story Guide lists each storyline in your data as a sequence of steps, showing what you've done, what's locked, and which mission opens the next stage. It works with plug-in storylines too.

  • Searchable live logs
  • Frame time per subsystem
  • Ship and planet inspector
  • Command console
  • Bug reports with logs attached

Bring your pilots with you.

Import

Windows .plt files and classic Mac pilots import directly. Keep several pilots in one store, each with its own backups.

iCloud

Imported game data syncs across your Apple devices through iCloud, so a pilot picked up on one device is ready on the next.

HD art and 3D models, from plug-ins.

Plug-ins can add high-resolution sprites and 3D ship and planet models. Models are rendered into the classic frames, so every ship keeps its shape and hit-boxes. It's off by default and runs on Apple platforms.

Live, real-time 3D is planned. It isn't built yet.

Play the beta, or build it.

The TestFlight beta covers all four Apple platforms. To build it yourself you need a Mac with Xcode. A Godot frontend for Linux and Windows is in progress.

You bring the game.

EV Nova's content belongs to ATMOS. This project ships no game data and never will. It reads a copy you own, at runtime, the same way OpenMW and OpenRA work.
